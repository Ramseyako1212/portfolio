## 📂 Featured Software Systems

### 1. WashQueue — Hybrid Queuing & Scheduling Platform
- **Scope**: Bacolod City and Western Visayas car wash businesses.
- **Architecture**: Monorepo with Customer PWA, Business Owner Dashboard, and Central Admin Console.
- **Specialty NLP**: Custom tokenizer and false-positive scrubber filtering Hiligaynon grammatical aspect markers before VADER sentiment polarity weighting.
- **Automated Testing**: 32 of 32 Cypress end-to-end integration test suites verified on production builds.
- **Repository**: [`Ramseyako1212/CARWASH`](https://github.com/Ramseyako1212/CARWASH)

### 2. Movie Popularity Prediction Engine
- **Focus**: Quantitative machine learning research isolating predictive metadata features (engagement, budget, release calendar).
- **Algorithms**: Ridge Regression with L2 Regularization, Random Forest, Gradient Boosting.
- **Results**: $R^2 = 0.84$ with zero data leakage across K-fold test splits.

### 3. CinemaSeat Reservation System
- **Focus**: Real-time cinema seat selection and ticketing platform for regional theaters in Negros Occidental.
- **Architecture**: Relational transactional locking to eliminate double-booking race conditions during seat selection.

### 4. Campus Lost & Found Centralized Management
- **Focus**: Multi-campus item tracking and 2-step security verification workflow.
- **Repository**: [`Ramseyako1212/lost-and-found`](https://github.com/Ramseyako1212/lost-and-found)

### 5. TradeLedger Financial Journal & Analytics
- **Focus**: Risk-to-reward ratio optimization, R-multiple tracking, and Microsoft Excel synchronization for currency and gold (XAUUSD) traders.
- **Repository**: [`Ramseyako1212/Trading-Journal`](https://github.com/Ramseyako1212/Trading-Journal)

### 6. Clinic GeoMap Discovery Engine
- **Focus**: Geospatial medical facility directory using Leaflet and the Haversine distance matrix algorithm.

### 7. Point of Sale (POS) & Inventory System
- **Focus**: Fast retail checkout, receipt calculation, and low-stock alert monitoring.
- **Repository**: [`Ramseyako1212/pos`](https://github.com/Ramseyako1212/pos)

## 💻 Local Development Setup

### Prerequisites
- [Node.js](https://nodejs.org/) (v18.0 or higher, v20+ recommended)
- [Git](https://git-scm.com/)

### 1. Clone the repository
```bash
git clone https://github.com/Ramseyako1212/portfolio.git
cd portfolio
```

### 2. Install dependencies
```bash
npm install
```

### 3. Start the local development server
```bash
npm run dev
```
Open your browser and navigate to `http://localhost:5173`.

### 4. Build for production
```bash
npm run build
```
The optimized production bundle will be output to the `dist/` folder.

### 5. Preview production build locally
```bash
npm run preview
```

## 🌐 Deployment Instructions

### Deploy to Vercel (Recommended — Zero Configuration)
1. Push your repository to GitHub under your account (`Ramseyako1212/portfolio`).
2. Log in to [Vercel](https://vercel.com/) with your GitHub account.
3. Click **Add New Project** and select your `portfolio` repository.
4. Set Framework Preset to **Vite**.
5. Leave the default settings:
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
   - **Install Command**: `npm install`
6. Click **Deploy**. Your portfolio will be live in under 60 seconds with a global CDN and automatic HTTPS!

### Deploy to Render
1. Log in to [Render](https://render.com/).
2. Click **New +** and choose **Static Site**.
3. Connect your GitHub repository `Ramseyako1212/portfolio`.
4. Configure settings:
   - **Build Command**: `npm run build`
   - **Publish Directory**: `dist`
5. Click **Create Static Site**.
